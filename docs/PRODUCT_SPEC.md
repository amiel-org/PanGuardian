# 产品方案

## 1. 产品定位

- 工作名：`盘管家（PanGuardian）`
- 产品目标：为 Windows 用户提供一个本地、可视化、可长期运行的 C 盘空间治理工具。
- 优先使用场景：
  - C 盘越来越大，但不知道是谁在涨
  - 微信、企业微信、桌面内容长期占用系统盘
  - 想要安全清理，又担心误删聊天记录、工作文件和系统关键数据
  - 想把一次清理变成长期巡查和预警

## 2. 目标用户

- 主用户：个人办公电脑用户
- 次级用户：公司同事、轻技术用户
- 用户特点：
  - 更关注是否真的释放了空间，而不是技术细节本身
  - 接受管理员权限，但希望所有高风险动作都经过确认
  - 需要本地离线和隐私可控

## 3. 产品原则

- 本地优先：默认不上传文件路径、文件内容和使用记录
- 安全优先：默认先扫描、再建议、后执行
- 可回滚优先：高影响操作必须支持回退
- 搬迁优先于删除：对微信、企业微信、桌面大文件优先提供迁移
- 长期治理优先于一次清理：必须有历史快照和增长预警

## 4. 关键问题

产品必须稳定回答以下问题：

1. C 盘空间到底被哪些目录、文件、应用占用了？
2. 哪些数据可以安全清理，哪些只能谨慎处理？
3. 哪些目录最近在持续增长？
4. 微信和企业微信哪些内容可以迁移到 D 盘，且不影响使用？
5. 桌面和下载目录中哪些文件应该被归档，而不是继续堆在 C 盘？

## 5. 核心能力

### 5.1 空间诊断

- 扫描 C 盘总体使用情况
- 按目录展示占用排行
- 按应用/来源展示占用排行
- 识别 Top 大文件、Top 高增长目录
- 展示最近 7 天 / 30 天增长趋势

### 5.2 安全清理

- 清理临时文件
- 清理回收站
- 清理浏览器缓存
- 清理缩略图缓存
- 清理日志与崩溃转储
- 清理部分 Windows 更新残留和安装缓存

### 5.3 微信 / 企业微信治理

- 自动识别微信和企业微信数据目录
- 将目录划分为：
  - 聊天记录数据库
  - 图片/视频/文件附件
  - 缓存和临时文件
  - 日志和崩溃数据
- 默认规则：
  - 聊天记录数据库：禁止自动删除，默认禁止自动迁移
  - 附件、媒体、缓存：允许迁移到 D 盘
  - 缓存、日志：允许清理
- 支持迁移向导：
  - 检查应用是否已退出
  - 选择迁移目标路径
  - 复制并校验
  - 建立目录联接
  - 启动应用验证
  - 失败回滚

### 5.4 桌面归档

- 扫描桌面大文件和旧文件
- 识别常见类型：
  - 安装包
  - 压缩包
  - 视频文件
  - 大尺寸图片
  - 临时导出文件
- 支持一键归档到 D 盘目录
- 支持按类型、日期、大小建立归档结构

### 5.5 巡查与预警

- 每日快扫
- 每周深扫
- 告警条件：
  - C 盘剩余空间低于阈值
  - 某目录 7 天内增长超过阈值
  - 微信/企业微信媒体目录异常增长
  - 桌面新增大文件
- 通知形式：
  - 应用内通知
  - Windows 托盘提示

## 6. 功能分级

### A 类：一键清理安全项

- `%TEMP%`
- 用户临时目录
- 回收站
- 缩略图缓存
- 浏览器缓存
- 常见应用日志

### B 类：确认后清理

- 下载目录中的旧安装包
- Windows 更新残留
- Crash dump
- 桌面旧文件

### C 类：只建议搬迁，不建议删

- 微信媒体与附件
- 企业微信媒体与附件
- 桌面大文件
- 大视频、大压缩包、大导出文件

### D 类：禁止自动处理

- 微信聊天正文数据库
- 企业微信核心数据库
- 用户文档目录
- Windows 系统关键目录

## 7. 非目标

- 不做杀毒和恶意软件查杀
- 不做云备份产品
- 不做跨平台第一版
- 不做远程集中运维平台

## 8. 典型用户流程

### 首次使用

1. 打开应用
2. 选择扫描范围和 D 盘归档目录
3. 执行首次深度扫描
4. 查看结果卡片和建议动作
5. 先清理安全项，再进入微信/企微迁移向导
6. 开启每日巡查和空间告警

### 日常使用

1. 托盘提示 C 盘异常增长
2. 打开增长详情页
3. 查看最近 7 天新增空间来源
4. 执行清理或迁移
5. 记录结果并更新趋势图

## 9. MVP 范围

### v0.1

- C 盘扫描
- 占用排行
- Top 大文件
- 安全项清理

### v0.2

- 微信/企业微信专项识别
- 迁移到 D 盘
- 桌面归档
- 回滚机制

### v0.3

- 快照对比
- 增长趋势
- 定时巡查
- 预警提醒

### v0.4

- 配置导入导出
- 打包分发给同事
- 基础诊断日志与问题反馈

## 10. 成功标准

- 首次使用可帮助用户定位主要膨胀源
- 安全项清理后能稳定释放可观空间
- 微信和企业微信迁移后不影响应用正常使用
- 用户能看懂“为什么 C 盘又变大了”
- 巡查功能能在空间不足前给出预警
